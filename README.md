## Engineering Approach

제가 중요하게 생각하는 기준은 다음과 같습니다.

1. **사용자가 실제로 편하게 사용할 수 있는가**
2. **장애가 발생했을 때 원인을 추적할 수 있는가**
3. **불필요하게 복잡하지 않은가**
4. **반복 가능한 형태로 운영·자동화할 수 있는가**

현장에서 시스템을 운영하며 쌓은 문제 해결 경험을 AI/LLM 인프라와 운영 자동화에 연결하는 것을 목표로 하고 있습니다.
